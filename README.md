## Как это работает

Приложение поднимает локальный WireGuard-интерфейс и передаёт его трафик через TURN/DTLS серверы VK, оборачивая пакеты в RTP с шифрованием ChaCha20-Poly1305. С точки зрения провайдера — это обычный зашифрованный VK-звонок.

```
Приложение → WireGuard → ChaCha20/RTP → VK TURN/DTLS → wdtt-server (VPS) → интернет
```

## Запуск

### Linux

**1. Установите зависимости:**

```bash
# Ubuntu/Debian
sudo apt install wireguard-tools libwebkit2gtk-4.1-dev

# Arch
sudo pacman -S wireguard-tools webkit2gtk-4.1
```

**2. Настройте права для WireGuard:**

Приложению нужны права root для управления сетевым интерфейсом. Установите sudoers-правило:

```bash
# Одной командой (скачает и запустит):
sudo bash <(curl -s https://raw.githubusercontent.com/luminescq/PWDTT/main/assets/install-sudoers.sh)
```

Или вручную через `visudo` — добавьте в `/etc/sudoers`:
```
your_user ALL=(ALL) NOPASSWD: /usr/bin/ip, /usr/bin/wg
```

Скрипт автоматически определит текущего пользователя и создаст файл `/etc/sudoers.d/pwdtt`.

**3. Запустите:**

```bash
chmod +x pwdtt-linux-amd64
./pwdtt-linux-amd64
```

### Windows

Скачайте `pwdtt-windows-amd64.exe` из [Releases](https://github.com/luminescq/PWDTT/releases) и запустите. Драйвер WireGuard (wintun) встроен.

### macOS

Скачайте `PWDTT-macos.zip` из [Releases](https://github.com/luminescq/PWDTT/releases), распакуйте и запустите `PWDTT.app`. При первом запуске macOS запросит разрешение на создание сетевого интерфейса — введите пароль администратора.

> Universal бинарник: работает на Intel и Apple Silicon (M1/M2/M3/M4).

## Быстрый старт

1. **Добавьте сервер** — кнопка `+` → вставьте `wdtt://`-ссылку или введите вручную
2. **VK-хеши** — Настройки → вставьте хеши из `vk.com/call/join/<hash>`
3. **Подключение** — кнопка питания

## Раздельное туннелирование

В **Настройках** → «Раздельное туннелирование» можно выбрать, какой трафик идёт через VPN:

- **Только список** — в туннель попадают лишь указанные адреса, подсети и домены, остальное идёт напрямую.
- **Всё кроме** — указанные адреса, сети и домены идут напрямую, остальной трафик — через VPN.

Список адресов задаётся в формате IP или CIDR, по одному в строке:

```
10.0.0.0/8
192.168.1.0/24
1.2.3.4
```

Отдельно можно указать **домены** (по одному в строке). Принимаются имена, URL и адреса с портом:

```
example.com
https://ozon.ru/catalog
yandex.ru:443
```

Домены резолвятся в IPv4-адреса **в момент подключения** (до установки маршрутов,
через системный DNS) и превращаются в `/32`-маршруты. Ошибка резолва одного имени
не срывает подключение — она попадает в лог, остальные маршруты применяются.

Поддерживается только IPv4 (одиночный адрес автоматически превращается в `/32`).
В режиме «Только список» IPv6 на время подключения блокируется: иначе браузер
брал бы AAAA-адрес сервиса и уходил напрямую, мимо VPN.
Маски (`*.example.com`) не поддерживаются: резолвить произвольные поддомены нельзя,
укажите конкретные имена. Если сервис сменил адреса, переподключитесь — маршруты
пересчитаются. Трафик к TURN/VK-серверам всегда идёт мимо туннеля, чтобы соединение
оставалось рабочим. Изменения применяются при следующем подключении.

Если в режиме **«Только список»** не задано ни одного адреса и ни один домен не
разрешился, в туннель не пойдёт ничего (полный туннель при этом не включается).

> Доменный режим работает по IP-адресам, полученным при резолве, а не по имени в
> каждом пакете. Для сервисов за CDN с большим пулом адресов пресеты объединяют
> подсети и домены: домены резолвятся в IPv4 при подключении.

### Пресеты

Чтобы не вводить адреса вручную, в блоке раздельного туннелирования есть готовые наборы:

- **Локальная сеть** — частные и служебные диапазоны (`10.0.0.0/8`, `192.168.0.0/16`, `172.16.0.0/12` и т.д.).
- **Яндекс**, **VK / Mail.ru**, **Ozon**, **Wildberries**, **Avito**, **Сбер** — IPv4-подсети сервисов.
- **Instagram**, **YouTube** — подсети Meta и Google плюс домены их CDN.
- **Telegram Desktop** — официальные подсети Telegram, включая CDN-диапазоны медиа (`91.108.16.0/22`, `91.108.20.0/22`), и домены веб-версии.
- **Нейросети** — ChatGPT, Claude, Gemini, DeepSeek, Grok, Mistral и Perplexity: подсети Google и Cloudflare плюс домены сервисов.
- **Twitch** — собственные подсети Twitch, Cloudflare и домены сайта, API, чата и видео.
- **Kick** — Cloudflare и домены сайта, API и статики.
- **Rutracker** — домены сайта: он полностью за Cloudflare, фиксированных подсетей нет.

Клик по пресету добавляет его подсети и домены к спискам, повторный клик — убирает.
Списки построены по анонсам автономных систем (RIPE RIS) и официальным диапазонам
Google; они могут меняться со временем, поэтому пресет — удобная отправная точка,
а не гарантия «всё учтено». Для исключения сервисов из VPN используйте режим
**«Всё кроме»**.

### Автозапуск в свёрнутом режиме

В Настройках есть переключатели **«Запускать при старте»** и **«Запускать свёрнутым»**.
Если оба включены, при входе в систему приложение стартует без окна:

- **Windows** — иконка в системном трее (двойной клик разворачивает окно);
- **Linux** — окно свёрнуто в панель задач;
- **macOS** — окно свёрнуто в Dock.

При обычном (ручном) запуске окно показывается как обычно.

## Ссылки

```
wdtt://<IP>:<DTLS_PORT>:<WG_PORT>:<PROXY_PORT>:<PASSWORD>[:<HASH1>,<HASH2>,...][#название]
```

- Поля 1–5 обязательны
- Хеши — опциональны, через запятую, до 4 штук
- `#название` — опциональный псевдоним сервера

Пример:
```
wdtt://1.2.3.4:56000:56001:0:mypassword:AbCdEfGh,XyZ12345#Мой сервер
```

Вставить ссылку можно через кнопку `+` или просто **Ctrl+V** в любом месте окна.

> Также принимаються ссылки qwdtt.

## Сборка из исходников

**Зависимости:** Go 1.26+, Node.js 22+, [Wails v2](https://wails.io)

```bash
# Linux
sudo apt install libayatana-appindicator3-dev pkg-config gcc libwebkit2gtk-4.1-dev
go install github.com/wailsapp/wails/v2/cmd/wails@latest

git clone https://github.com/luminescq/PWDTT
cd PWDTT
wails build -platform linux/amd64 -tags webkit2_41 -o pwdtt-linux-amd64
# → build/bin/pwdtt-linux-amd64
```

```bash
# Windows (кросс-компиляция с Linux)
wails build -platform windows/amd64
# → build/bin/pwdtt.exe
```

```bash
# macOS (только на macOS)
wails build -platform darwin/universal
# → build/bin/pwdtt-macos
```

## Отчёт об ошибках

Если приложение работает некорректно, вы можете собрать отчёт прямо из интерфейса:

1. Откройте **Настройки** (шестерёнка вверху)
2. Нажмите **Отчёт** — информация о системе и логах сессии скопируется в буфер обмена
3. Создайте [Issue](https://github.com/luminescq/PWDTT/issues/new) и вставьте отчёт

Отчёт содержит: версию ОС, версию Go, версию приложения, имя хоста и.filtered логи текущей сессии.
